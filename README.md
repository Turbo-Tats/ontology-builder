# ontology-builder

A Claude Code skill that helps product managers document one area of an app as a business ontology and an interactive knowledge graph.

The skill lives in [`.claude/skills/ontology-builder/`](./.claude/skills/ontology-builder/). See its [README](./.claude/skills/ontology-builder/README.md) for what it produces, how to install it and how to use it.
